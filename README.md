## ⚡ Особенности и возможности сайта

- **🔍 Мгновенный глобальный поиск (`Ctrl + K` или `/`)**:
  - Быстрый живой поиск по всей базе (более **1 250 записей**).
  - Моментально находит способности, камни, богов, уникальные предметы, свитки, заклинания или механику с прямым переходом к нужному разделу.
- **📚 16 интерактивных категорий**:
  1. **Главная**: витрина сборки, быстрые ссылки на все разделы, кнопка быстрого копирования команды тестовой комнаты `coc dev`.
  2. **База и механики**: система опыта, урон, резисты, бой, скрытность, карманные кражи и интерактивная таблица штрафов интоксикации от зелий.
  3. **Расы и Камни Судьбы**: 24 врожденные способности и 19 камней судьбы с динамическим скалированием от характеристик.
  4. **Аэдра**: 9 священных богов с аутентичными иконками амулетов, дарами, благословениями и прогрессией молитв.
  5. **Даэдра**: 16 принцев Даэдра, их сферы влияния, подношения, артефакты богов и квесты.
  6. **Проклятые**: ветки способностей Вампира и Вервольфа с градацией чистоты крови (ЧК 1–5) и уникальными талантами.
  7. **Ветки способностей**: интерактивный обозреватель всех 18 навыков (Воин, Маг, Вор) с фильтрацией по уровням.
  8. **Расходники**: фильтруемые таблицы зелий (восполнения и усиления), ядов, стакающейся еды, алкоголя, свитков и посохов.
  9. **Зачарования**: таблица тиров (I–V) и матрица совместимости эффектов со слотами снаряжения.
  10. **Заклинания и Ту'умы**: каталог из 590+ заклинаний по школам магии, дуалкаст-коэффициенты и слова Криков.
  11. **Саммоны**: база призываемых существ, параметры духов, нежити и даэдра, урон, ауры и сопротивления.
  12. **Снаряжение**: сравнительная таблица оружия (ДПС, урон, дальность, скорость атаки, вес) по материалам.
  13. **Уникальные предметы (740+)**: фильтрация по категориям и копирование консольного кода `player.additem ID 1` в один клик.
  14. **Уровни сложности**: сравнительная матрица 4 режимов с оригинальными графическими баннерами и хардкорными правилами.
  15. **Черные книги**: 7 книг Апокрифа с выбором пассивных сил и локациями курганов.
  16. **Награды за квесты**: интерактивный трекер древних нордских монет (цель — 2 150 монет) с сохранением галочек в браузере.
- **★ Личные закладки (Избранное)**: сохранение способностей и предметов в локальное хранилище браузера (`localStorage`).
- **📱 Адаптивный дизайн**: продуманный интерфейс для смартфонов, планшетов и широкоформатных мониторов.
- **🚀 100% Client-Side**: работает автономно, без сервера, базы данных или Node.js. Можно открыть локально простым двойным кликом по `index.html`.

## 🔄 Как обновлять данные при изменении базы

Если вы обновите исходную базу, вы можете в одну команду перегенерировать все JSON файлы:

```bash
python scripts/export_all_data.py
```

После этого зафиксируйте изменения и отправьте их на GitHub:

```bash
git add data/
git commit -m "update: refresh game data"
git push
```
GitHub Pages автоматически применит обновление за несколько секунд!
